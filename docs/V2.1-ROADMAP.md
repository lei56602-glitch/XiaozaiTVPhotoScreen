# 小李视觉 V2.1 开发规划

## 产品定位
小李视觉是 Android TV 家庭照片管理与大屏展示中心。V2.1 以现有 V2.0 为基础，优先改善界面、图片管理、播放体验、手机上传和长期稳定性。

## 永久产品原则
- 全程无广告：不接入广告 SDK，不设置开屏、横幅、视频、弹窗广告或商业推广位。
- 不做付费解锁。
- 不未经用户确认删除照片。
- 应用升级不得主动清除应用内照片、相册数据和设置。
- 电视遥控器为主要操作方式，触摸操作作为补充。
- 先保证稳定性和可用性，再增加智能功能。

## V2.1 优先范围

### 1. 界面与交互
- 统一深海军蓝、深蓝灰和科技蓝视觉规范。
- 首页以大图为核心，左侧窄导航、顶部状态信息、底部横向缩略图带。
- 减少首页功能卡片和冗余文字。
- 导航选中态、遥控器焦点态清晰一致。
- 统一页面边距、卡片圆角、图标和字体。
- 页面切换、按钮焦点和图片切换动画自然且可关闭/降低。
- 图片管理页采用清晰的标题/工具栏/网格/批量操作分区。
- 手机上传页独立呈现二维码，首页不得显示二维码。
- 全屏播放默认隐藏控制栏，用户操作后显示并自动隐藏。
- 空图库、网络异常、上传失败、存储不足均提供清楚的状态页或提示。

### 2. 图片导入与管理
- 支持电视本地文件选择器和多选导入。
- 保留图片真实文件格式和扩展名，不得将 PNG/WebP 等内容错误命名为 JPG。
- 导入任务在后台执行，显示结果；失败可重试。
- 图片网格支持单选、多选、全选、批量删除。
- 删除前二次确认，只删除应用内部副本。
- 收藏、相册/分类、搜索和排序。
- 显示文件名、格式、分辨率、文件大小和添加时间。
- 删除、移动或清理时同步维护缩略图缓存和数据库记录。

### 3. 播放体验
- 顺序、随机、单张循环播放。
- 上一张、下一张、播放、暂停。
- 3/5/10/15/30/60 秒播放间隔。
- 叠化渐变和可配置的转场效果。
- FIT_CENTER、CENTER_CROP、原始比例等适配方式。
- 竖图可选模糊背景填充。
- 记住播放位置、相册和播放设置。
- 全屏播放支持遥控器操作，返回键行为可靠。

### 4. 手机上传
- 二维码仅在手机上传页面显示。
- 同一局域网内访问，显示可复制的地址和连接状态。
- 支持多图上传、进度反馈、成功/失败状态和失败重试。
- 对上传文件名做安全处理，校验文件类型和大小。
- 上传接口增加会话/访问验证，避免局域网内任意设备随意写入。
- 上传结束后图库可靠刷新，网络中断时给出明确反馈。

### 5. 设置、数据与稳定性
- 中英文界面覆盖所有页面，并记住语言选择。
- 显示图库占用和剩余空间。
- 提供缓存清理，但不得误删原图。
- 图片分页/按需加载、缩略图缓存、后台解码和大图采样，降低内存峰值。
- 损坏图片跳过并记录，不导致整个图库崩溃。
- 保存图片、相册、收藏、播放设置和上次播放位置。
- 备份/恢复设置和图库索引；恢复前明确提示。
- 网络/上传服务状态提示和基础错误日志。
- 应用升级保持 applicationId 与签名兼容，升级不清除用户数据。

### 6. Android TV 遥控器
- 方向键、OK、返回、菜单键行为明确。
- 所有主要页面和操作无需触摸即可完成。
- 页面切换后焦点落在合理位置，不丢焦点。
- 弹窗关闭后恢复原焦点。
- 长列表和网格支持稳定的方向键移动。

## 后续版本候选（不作为 V2.1 发布阻塞项）
- 手机远程控制电视播放。
- 家庭成员共享相册、多设备上传。
- 图片时钟、艺术画廊、照片墙和多图拼图模式。
- 屏幕保护、定时切换相册、节日/纪念日播放。
- 回忆模式、场景识别、人物分类和智能照片推荐。
- 多台电视同步和自动场景编排。

## V2.1 验收要求
- GitHub Actions 云端构建成功并生成 APK。
- 手机安装测试：页面、导入、删除、上传、全屏、播放和数据持久化。
- 电视实机测试：横屏布局、遥控器焦点、方向键/OK/返回/菜单键、性能和长时间播放。
- 对未在真实设备测试的项目，明确标注“未验证”，不得宣称已通过。
- 发布前确认无广告 SDK、无广告位、无商业推广内容。

## 版本与分支
- 基线：v2.0-development 当前稳定提交。
- V2.1 开发分支：v2.1-development。
- 正式版本只有在核心验收通过后才创建 Release。
